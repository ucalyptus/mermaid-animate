# Mermaid Animate

A React-based web application for creating and animating [Mermaid.js](https://mermaid.js.org/) diagrams. This tool allows you to convert your Mermaid diagrams into animated GIFs.

## Features

- Create Mermaid diagrams using the standard Mermaid.js syntax
- Real-time diagram preview
- Export diagrams as animated GIFs
- Modern UI with Tailwind CSS
- Built with TypeScript for type safety

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Mermaid.js
- gif.js for GIF generation
- html-to-image for diagram capture

## Prerequisites

- Node.js v18.20.4 or higher
- npm v10.7.0 or higher

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ucalyptus/mermaid-animate.git
   cd mermaid-animate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Development

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Building for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Linting

To run the linter:

```bash
npm run lint
```
